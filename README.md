# Character Continuity System

Paket ini menambahkan Character Continuity System sebagai sistem pemeriksaan lintas-domain.

## Struktur

- `core/universe/model/continuity.ts`
- `docs/character-continuity-system.md`
- `tests/unit/universe-model/continuity.test.ts`
- `apply.mjs`

## Prinsip

Continuity tidak menciptakan Canon, tidak mengubah sumber data, dan tidak melakukan auto-repair.

Paket mengikuti struktur repository langsung tanpa folder `phase`, `patch`, atau wrapper tambahan.
