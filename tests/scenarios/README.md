# Scenario Test Harness

## Purpose & Scope
This directory will house end-to-end simulation scenario tests.

### Intended Execution Hierarchy:
```
scenario specification
  → engine execution
  → state transitions across domain owners
  → multi-domain validation & consensus
  → expected simulation result
```

Actual Universe domain scenarios (such as full diurnal cycle completions or multi-character narrative interactions) will be authored once domain engines are introduced in future phases.
