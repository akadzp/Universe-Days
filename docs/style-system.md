# Character Style System

Style adalah domain komunikasi karakter yang menjelaskan **bagaimana** sesuatu diekspresikan.

## Batas kepemilikan
Style tidak memiliki authority atas:
- Personality → Character Profile / SIMS
- tindakan/pola tindakan → Behavior System
- kondisi emosional saat ini → State System
- fakta yang diketahui → Knowledge System
- isi hubungan → Relationship System

## Aturan inti
Satu ucapan atau gaya sesaat tidak otomatis menjadi Style persisten. Story-derived Style memerlukan sedikitnya dua bukti atau signifikansi naratif yang jelas. Perubahan Style mempertahankan snapshot sebelumnya dan membutuhkan trigger.

`AI_PROPOSAL` dan `UNKNOWN` tidak dapat menjadi sumber otoritatif.
